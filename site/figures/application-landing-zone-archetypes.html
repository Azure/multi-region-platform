1Hybrid-Connected Applications
Significant dependencies on on-premises environments, enterprise networks, or centralized shared services that require persistent private connectivity.
  • Persistent private connectivity
  • Profile set by dependency latency, resiliency, regulation, operations
  • Common in migrations and hybrid scenarios
Typical connectivity profiles
Remote hubMinimal hubFull hub
2Isolated Cloud-Native or AI Applications
Self-contained workloads that can operate without persistent private connectivity to enterprise, on-premises, or centralized shared-service dependencies.
  • No persistent private dependencies
  • Can often use disconnected spokes
  • Flexible placement across regions
Typical connectivity profiles
Disconnected spokesConnected, where justified
3Connected Cloud-Native or AI Applications
Primarily self-contained cloud-native or AI applications that require private connectivity to selected enterprise services, data sources, APIs, or other Azure environments.
  • Private access to selected dependencies
  • Profile set by latency, traffic, resiliency, security
  • Common for data, analytics, and AI platforms
Typical connectivity profiles
Remote hubMinimal hubFull hub
4Interconnected Application Portfolios
Groups of applications with meaningful dependencies on each other — shared data, common services, east-west communication, or coordinated connectivity and operations.
  • Portfolio-level archetype
  • Aggregate requirements set the profile
  • Direct spoke-to-spoke or a regional hub for east-west traffic
Typical connectivity profiles
Remote hubMinimal hubFull hub
