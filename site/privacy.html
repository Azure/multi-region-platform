Privacy and Microsoft Clarity

We use Microsoft Clarity to capture how you use and interact with this website through behavioral metrics, heatmaps, and session replay. We use these insights to understand which content and tools visitors use, identify usability issues, and improve the website's content and usability.

Website usage data is collected through first- and third-party cookies and other tracking technologies. Heatmaps summarize interactions such as clicks and scrolling; session replay helps us review how visitors navigate and interact with pages.

For more information about how Microsoft collects, uses, and protects your data, visit the Microsoft Privacy Statement.

Support

For documentation corrections, non-security bugs, and feature suggestions, raise an issue in the GitHub repository. Include the affected article or tool, the current and expected behavior, and reproducible steps where relevant. Do not include credentials, customer planning records, or other confidential information.

Do not report security vulnerabilities in public issues. Follow the repository's security reporting guidance.

Contributing

This project welcomes contributions and suggestions. See the contribution guidelines for the authoring and pull request process.

Most contributions require you to agree to a Contributor License Agreement (CLA) declaring that you have the right to, and actually do, grant us the rights to use your contribution. For details, visit Microsoft's Contributor License Agreement site.

When you submit a pull request, the CLA bot will determine whether you need to provide a CLA and mark the pull request appropriately, for example with a status check or comment. Follow the bot's instructions. You only need to do this once across repositories using Microsoft's CLA.

This project has adopted the Microsoft Open Source Code of Conduct. For more information, see the Code of Conduct FAQ or contact opencode@microsoft.com with questions or comments.
