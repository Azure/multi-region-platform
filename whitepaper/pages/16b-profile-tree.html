Which profile should this region provide?

Each question comes from the “fits when” criteria of the profiles. Stop at the first profile that satisfies the requirements identified in check 3. Two of the four profiles need no local hub, and only the Full Regional Hub approaches the footprint of an existing geographic hub.

Workload scenarios expected in the region
1Do the workloads require private access to enterprise services, on-premises systems, centralized security inspection, another application portfolio, or geographic-hub capabilities?
2Can they tolerate the latency, availability coupling, data-transfer implications, and dependency on connectivity to another region?
3Do requirements justify a comprehensive local capability set — local hybrid connectivity, substantial shared services, strict latency or data-boundary controls, or independence from other hubs?
