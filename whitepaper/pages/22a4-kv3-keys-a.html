Keys: vault-based patterns

Patterns 1 and 2 use Key Vault. Customer-managed keys have extra limits, so design them separately from secrets.

1One Key Vault per region
Created in
Key Vault Standard or Premium, one vault per workload per region.
Outage
Each region works on its own vault, full read and write.
Best for
Workloads whose services can use a separate key in each region.
Watch for
Services that geo-replicate cannot use two vaults. Storage with GRS uses one key from one vault for both copies, so a vault outage affects both.
2One Premium vault per region + external HSM
Created in
Imported from your external HSM (BYOK) into a Premium vault in each region.
Outage
Each region works on its own vault, full read and write.
Best for
You must own and hold the master key, or meet BYOK rules, and want to control recovery time.
Watch for
Same service limits as pattern 1, and extra cost.

Check before you pick

Confirm that every service using the key supports a vault per region. Standard does not support BYOK; check supported HSMs for Premium. Restoring a vault backup works only within the same subscription and geography.
